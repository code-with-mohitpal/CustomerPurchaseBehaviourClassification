# Customer Purchase Behaviour Prediction

## 📌 Project Overview

This project predicts customer purchasing behaviour using Machine Learning techniques including Classification and Regression.

## 🔧 Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* XGBoost

## 📊 Models Used

* Logistic Regression
* Naive Bayes
* Gradient Boosting
* XGBoost

## 📁 Dataset

Customer Personality Analysis dataset from Kaggle

## 🎯 Objectives

* Predict customer purchase decisions
* Estimate spending behaviour
* Generate business insights

## 🚀 Results

* Improved prediction accuracy using ensemble models
* Identified high-value customers
